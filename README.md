## 🎯 Featured Projects

### 🤖 Autopilot — Multi-Agent Resume-Tailoring & Job-Application Platform
**Live in production** — a multi-agent system that autonomously runs a daily, end-to-end job-application pipeline: discovering roles, tailoring a resume per role, and delivering a digest, unattended.

- **Five specialised agents** — search, extract, match, writer, packager — coordinated by a LangGraph-style planner and supervisor loop
- Each agent calls tools over web-search, web-fetch, filesystem, Drive, Sheets and Gmail, exposed through the **Model Context Protocol**
- Matching ranks every role with **sentence-transformer embeddings + cosine similarity** before any generation happens
- Writer agent emits **ATS-optimised, JD-tailored LaTeX** resumes and cover letters under schema validation, compiling to PDF automatically
- Guardrails: dedup store (zero duplicate applications), hard daily budget cap on agent turns and cost, and a **prepare-only, never-auto-submit** safety rule

**Tech**: Python, LangGraph, MCP, Sentence Transformers, LaTeX, Gmail API, Google Sheets

### 💼 [JobEasy — AI-Powered Full-Stack Hiring SaaS](https://jobeasy.app)
A deployed AI job-search platform covering resume management, ATS analysis, job tracking and application workflows — built and shipped solo.

- **ATS resume-matching engine** on Sentence Transformers, embeddings and cosine similarity
- LLM integration for resume tailoring, **keyword-gap analysis** and job-specific content generation
- AutoApply and job-tracking workflows via Python automation, API integrations and scheduled tasks
- Automated email notifications and a Kanban-style application tracker

**Tech**: FastAPI, React, PostgreSQL, Sentence Transformers, Python, REST APIs
**Live**: [jobeasy.app](https://jobeasy.app)

### 🧠 Nexus — RAG-Powered Second-Brain Knowledge Platform
A retrieval system that ingests PDFs, markdown and web content, then answers against it with **grounded, evaluated retrieval** rather than raw vector-search guesswork.

- Deliberate chunking + embeddings over three source formats
- **ChromaDB** vector search with metadata filtering to constrain the candidate set before ranking
- **Retrieval evaluation** (hit-rate, faithfulness, answer relevance) measured before anything reaches the model
- AI-based tagging, entity extraction and document linking, plus automated summaries and briefings

**Tech**: Python, ChromaDB, Embeddings, LLM APIs, Metadata Filtering

### 🛒 Retail Vision — Real-Time Theft & Shoplifting Detection
A real-time surveillance system that detects and tracks people across retail footage and flags theft-indicating behaviour to control-room staff. *(Team Lead)*

- **YOLOv8** detection with **DeepSORT** persistent multi-object tracking, handling partial occlusion and motion blur
- Behaviour-analysis module flagging **loitering, erratic back-and-forth motion and prolonged dwell time** via temporal frame counts and Euclidean distance heuristics
- YOLOv8n trained on a custom COCO-format dataset (70/15/15) covering occlusion, crowding and variable lighting
- Async **FastAPI** backend with structured JSON results, plus a React + Tailwind control-room dashboard with bounding-box overlays and timestamped alerts

**Tech**: YOLOv8, DeepSORT, OpenCV, FastAPI, React, Tailwind CSS

### 📰 Fake News Detection — NLP Classification System
Full ML lifecycle on a binary fake-news classifier: EDA, an NLP preprocessing pipeline (TF-IDF, tokenization, stemming), training and cross-validated evaluation — benchmarking Logistic Regression, Naive Bayes and SVM on F1/precision/recall, shipped as an interactive inference app.

**Tech**: Python, scikit-learn, NLP, TF-IDF, SVM
